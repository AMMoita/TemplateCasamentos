README-TEMPLATE
Template de Website de Casamento
Guia de recolha de conteúdos para personalização

==================================================
1. OBJETIVO DESTE DOCUMENTO
==================================================

Este ficheiro serve de apoio à personalização do website de casamento para cada casal.

Antes de iniciar a adaptação do template, é importante recolher com os noivos toda a informação necessária para preencher corretamente as várias secções do site, evitar omissões e garantir coerência entre páginas, datas, textos, imagens e links.

Este template inclui várias páginas e secções informativas. Nem todas têm de ser usadas obrigatoriamente, mas idealmente deve ser decidido logo no início quais as páginas a manter, remover ou adaptar.

==================================================
2. ESTRUTURA ATUAL DO SITE
==================================================

O template atual inclui os seguintes ficheiros/páginas principais:

- index.html
- o-nosso-dia.html
- testemunhas.html
- alojamento.html
- confirmacao.html
- style.css
- assets/ (imagens, ícones, etc.)

Com base na análise do template, o site apresenta atualmente:

- secção principal com nomes dos noivos e data
- contagem decrescente
- mensagens introdutórias
- cronologia / história / momentos do dia
- secção sobre testemunhas / padrinhos / pessoas especiais
- galeria / imagens
- informações logísticas
- formulário de confirmação de presença
- mapa / localização
- contactos e/ou notas úteis
- links externos e integração com calendário

==================================================
3. INFORMAÇÕES NECESSÁRIAS A PEDIR AOS NOIVOS
==================================================

Abaixo está a lista de informação que deve ser pedida ao casal para personalizar o site.

------------------------------------------
3.1. DADOS PRINCIPAIS DO CASAMENTO
------------------------------------------

Informações necessárias:

- Nome completo da noiva
- Nome completo do noivo
- Forma como os nomes devem aparecer no site
  Exemplo:
  - "Ana & João"
  - "Joana e Miguel"
  - nomes completos
  - nomes próprios apenas
- Data do casamento
- Hora da cerimónia
- Hora de chegada recomendada aos convidados
- Data e hora do copo de água / receção / festa, se diferente da cerimónia
- Frase principal do casal para o topo do site, caso pretendam
- Pequeno texto de introdução / boas-vindas

Confirmar também:

- Qual é a data oficial que deve aparecer em todo o site
- Qual o formato pretendido para a data
  Exemplo:
  - 12 de Junho de 2027
  - 12.06.2027
  - Saturday, June 12, 2027

------------------------------------------
3.2. LOCAIS DO EVENTO
------------------------------------------

Informações necessárias:

- Nome do local da cerimónia
- Morada completa da cerimónia
- Link Google Maps da cerimónia
- Coordenadas GPS, se necessário
- Nome do local da festa / quinta / receção
- Morada completa da festa
- Link Google Maps da festa
- Indicações adicionais de acesso, estacionamento ou portaria
- Informação sobre estacionamento
- Informação sobre acessibilidade
- Informação sobre transporte entre locais, se existir

Se a cerimónia e a festa forem no mesmo local, confirmar isso claramente.

------------------------------------------
3.3. HORÁRIOS / PROGRAMA DO DIA
------------------------------------------

Informações necessárias:

- Hora da chegada dos convidados
- Hora do início da cerimónia
- Hora prevista para cocktail / receção
- Hora do jantar
- Hora do corte do bolo
- Hora da abertura do baile / festa
- Hora de encerramento, se aplicável

Caso o template inclua uma timeline ou agenda, confirmar a ordem e os títulos exatos de cada momento.

Exemplo de dados a recolher:

- 15:00 — Chegada dos convidados
- 15:30 — Cerimónia
- 17:00 — Cocktail
- 19:30 — Jantar
- 23:00 — Corte do bolo
- 00:00 — Abertura do baile

------------------------------------------
3.4. HISTÓRIA DO CASAL / TEXTOS PERSONALIZADOS
------------------------------------------

Informações necessárias:

- Texto de apresentação do casal
- História de como se conheceram
- História do pedido de casamento, se quiserem incluir
- Mensagem aos convidados
- Texto para a secção “O nosso dia”
- Texto para a secção final / agradecimento
- Frases especiais, citações ou versículos, se desejado
- Texto para dress code, notas logísticas ou observações especiais

Idealmente pedir:

- texto final já aprovado pelos noivos
ou
- notas soltas para posterior redação

------------------------------------------
3.5. CONTAGEM DECRESCENTE
------------------------------------------

Informações necessárias:

- Data exata do evento
- Hora exata do evento a usar para a contagem
- Fuso horário / país do evento, caso o casamento não seja em Portugal

Importante:
A data da contagem tem de ser exatamente a mesma usada no restante site, para evitar incoerências.

------------------------------------------
3.6. TESTEMUNHAS / PADRINHOS / PESSOAS ESPECIAIS
------------------------------------------

A página `testemunhas.html` está preparada para apresentar pessoas importantes do casamento.

Informações necessárias:

- Nome de cada testemunha / padrinho / madrinha / dama de honor / best man / etc.
- Papel de cada pessoa no casamento
- Pequena descrição de cada pessoa
- Fotografia de cada pessoa
- Ordem pela qual devem aparecer
- Confirmar se esta página é para manter ou remover

Caso o casal não queira esta secção:
- remover do menu
- remover a página
ou
- adaptar a outra finalidade

------------------------------------------
3.7. GALERIA / FOTOGRAFIAS
------------------------------------------

Informações necessárias:

- Fotografias oficiais a usar no site
- Fotografia principal para a home
- Fotografias para banner / hero
- Fotografias para secções internas
- Fotografias para galeria, se existir
- Ordem preferida das imagens
- Indicação se alguma imagem deve ser destacada
- Legendas, se pretendidas

Requisitos recomendados para imagens:

- boa resolução
- orientação adequada ao layout
- ficheiros otimizados para web
- nomes organizados por secção

Exemplo de organização útil:
- home-01.jpg
- casal-01.jpg
- historia-01.jpg
- testemunha-ana.jpg
- local-festa.jpg

------------------------------------------
3.8. CONFIRMAÇÃO DE PRESENÇA (RSVP)
------------------------------------------

A página `confirmacao.html` inclui formulário de confirmação, pelo que deve ser definido com os noivos exatamente o que pretendem recolher.

Informações necessárias:

- Data limite para confirmação
- Se a confirmação é individual ou por agregado/família
- Campos obrigatórios do formulário
- Se querem recolher:
  - nome completo
  - número de convidados
  - presença sim/não
  - restrições alimentares
  - intolerâncias
  - alergias
  - pedido de menu vegetariano/vegan
  - contacto telefónico
  - email
  - mensagem dos convidados
- Texto introdutório da secção RSVP
- Texto de agradecimento após submissão
- Informação sobre para onde vão os dados do formulário
  Exemplo:
  - email
  - Google Sheets
  - base de dados
  - formulário externo

Confirmar também:

- se haverá confirmação separada para adultos e crianças
- se será pedido nome de cada convidado
- se será necessário indicar música sugerida
- se querem recolher informação sobre transporte ou alojamento

------------------------------------------
3.9. ALOJAMENTO / INFORMAÇÕES ÚTEIS
------------------------------------------

A página `alojamento.html`, neste template, está a funcionar como página de informações úteis/logística e pode incluir alojamento, transportes ou recomendações.

Informações necessárias:

- Lista de hotéis/alojamentos recomendados
- Nome de cada alojamento
- Morada
- Distância até ao local do casamento
- Contactos
- Website
- Código promocional, se existir
- Data limite de reserva, se existir
- Informação sobre transfers, se existirem
- Informação útil adicional:
  - estacionamento
  - táxis
  - TVDE
  - igrejas próximas
  - farmácias
  - pontos de referência
  - recomendações para convidados de fora

Confirmar com os noivos:

- se esta página será apenas sobre alojamento
- ou se será uma página geral de “Informações úteis”

------------------------------------------
3.10. MAPA / LOCALIZAÇÃO
------------------------------------------

Informações necessárias:

- Local exato a mostrar no mapa
- Link embed ou link do Google Maps
- Nome do local a apresentar
- Morada curta e morada completa
- Instruções especiais para entrada, portão, estacionamento ou percurso

Importante:
O mapa não deve ficar genérico; deve ser substituído pela localização real do evento.

------------------------------------------
3.11. INTEGRAÇÃO COM CALENDÁRIO
------------------------------------------

O template atual inclui indícios de ligação para adicionar o evento ao calendário.

Informações necessárias:

- Nome oficial do evento
  Exemplo:
  - Casamento Ana e João
- Data de início
- Data de fim
- Hora de início
- Hora de fim
- Local
- Descrição do evento
- Link final para Google Calendar / iCal / Outlook, se for para manter

Importante:
Os dados do calendário têm de coincidir exatamente com os textos mostrados no site.

------------------------------------------
3.12. CONTACTOS
------------------------------------------

Informações necessárias:

- Contacto telefónico principal
- Email de contacto
- Nome da pessoa responsável por dúvidas
- Se o contacto deve ser dos noivos ou de outra pessoa
  Exemplo:
  - wedding planner
  - testemunha
  - familiar responsável
- Horário / contexto para contacto, se relevante

------------------------------------------
3.13. REDES SOCIAIS / LISTA DE PRESENTES / OUTROS LINKS
------------------------------------------

Caso o template venha a incluir ou o casal pretenda acrescentar:

Informações necessárias:

- hashtag oficial do casamento
- Instagram ou outro perfil, se quiserem partilhar
- link para lista de presentes
- NIB / IBAN / MB WAY, se optarem por essa solução
- link para álbum partilhado
- link para confirmação externa
- link para recomendações adicionais

Estas informações só devem ser usadas se os noivos desejarem explicitamente.

==================================================
5. DECISÕES A TOMAR COM OS NOIVOS
==================================================

Antes de iniciar a edição final, confirmar com o casal:

- Quais as páginas que querem manter
- Quais as páginas que querem remover
- Se querem testemunhas/padrinhos no site
- Se querem galeria
- Se querem lista de alojamento
- Se querem mapa
- Se querem contador decrescente
- Se querem formulário RSVP no próprio site
- Se pretendem integração com calendário
- Se preferem um tom mais clássico, moderno, romântico ou minimalista
- Se o site será em português, inglês ou bilingue

==================================================
6. VALIDAÇÕES IMPORTANTES ANTES DE PUBLICAR
==================================================

Antes da entrega/publicação, validar sempre:

- A mesma data aparece corretamente em todas as páginas
- O mesmo local aparece corretamente em todas as páginas
- Os nomes dos noivos estão consistentes em todo o site
- A contagem decrescente aponta para a data certa
- O link do calendário está correto
- O mapa aponta para o local real
- O formulário RSVP funciona corretamente
- Todos os links abrem corretamente
- Não existem textos de demonstração por substituir
- Não existem nomes fictícios da versão template
- Todas as imagens foram substituídas pelas finais
- O menu aponta para as páginas corretas
- O site está responsivo em telemóvel

==================================================
7. OBSERVAÇÕES ESPECÍFICAS DETETADAS NESTE TEMPLATE
==================================================

Durante a análise do template atual, foram identificados alguns pontos que devem ser revistos sempre que o site for personalizado:

- Existem dados de demonstração que precisam de ser substituídos integralmente
- A data apresentada na homepage deve ser confirmada e uniformizada com a data mostrada nas páginas internas
- A página “O nosso dia” deve usar exatamente os mesmos horários/logística definidos pelo casal
- O link de calendário deve ser reconstruído com os dados reais dos noivos
- O mapa deve ser atualizado para a localização real
- A página `alojamento.html` pode ser usada como:
  - página de alojamento
  - página de logística
  - página de informações úteis
- A secção de testemunhas deve ser confirmada com os noivos antes de manter
- O formulário RSVP deve ser ligado ao método real de receção de respostas

==================================================
8. MODELO RESUMIDO PARA ENVIAR AOS NOIVOS
==================================================

Pode ser enviado ao casal um pedido resumido com a seguinte estrutura:

INFORMAÇÕES NECESSÁRIAS PARA PERSONALIZAR O VOSSO SITE

1. Dados principais
- nomes dos noivos
- data do casamento
- hora da cerimónia
- hora da receção/festa
- frase principal ou mensagem de boas-vindas

2. Locais
- nome e morada da cerimónia
- nome e morada da festa
- links Google Maps
- indicações de estacionamento/acesso

3. Programa do dia
- horários principais do evento

4. Textos
- breve apresentação do casal
- história / mensagem aos convidados
- texto para RSVP
- notas úteis/logísticas

5. Testemunhas / padrinhos
- nomes
- papel
- pequena descrição
- fotografia

6. Imagens
- fotografias do casal
- imagem principal
- imagens adicionais para galeria

7. RSVP
- data limite de resposta
- dados a recolher no formulário
- restrições alimentares, se aplicável

8. Alojamento / logística
- hotéis recomendados
- contactos
- transportes
- outras informações úteis

9. Contactos
- telefone/email para dúvidas dos convidados

10. Extras
- link de lista de presentes
- redes sociais / hashtag
- link para calendário
- outros links úteis

==================================================
9. NOTA FINAL
==================================================

Este template deve ser sempre revisto página a página após inserção dos conteúdos finais.

Nunca assumir que basta alterar apenas a homepage. É necessário verificar:
- textos
- datas
- horários
- ligações
- imagens
- mapa
- formulário
- metadados e links externos

O objetivo é que o site final fique totalmente coerente, sem vestígios da versão de demonstração, e reflita fielmente as preferências e logística reais do casamento.
